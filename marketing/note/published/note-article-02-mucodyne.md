# 【公的資料ベース】ムコダイン（カルボシステイン）の飲ませ方｜おすすめ食品と注意点まとめ

ムコダイン（カルボシステイン）は、子どもの風邪でよく処方される痰切りの薬です。

でも、混ぜるものによっては味が変わることも。この記事では、国立成育医療研究センターの公開資料をもとに、**相性の良い食品・避けた方がいい食品**をまとめました。

✅ おすすめ: 牛乳、アイス、ヨーグルト、りんごジュース、オレンジ飲料、スポーツ飲料
⚠ 避けた方がいい: ココア、プリン、お茶

## 複数の薬を処方された場合

風邪の時は、ムコダインと一緒に他の薬が処方されることがよくあります。

複数の薬を処方されたとき、全部に共通して使える食品を確認したい場合は「おくすり味ナビ」の複数薬まとめ機能が便利です。薬を選ぶだけで、共通のおすすめとNGが一目でわかります。

## この薬について

| 項目 | 内容 |
|------|------|
| 商品名 | ムコダインDS33.3% |
| 一般名 | カルボシステイン |
| 製造元 | 杏林製薬 |
| 味 | 甘酸っぱい（出典PDFの表記による） |
| 主な用途 | 痰の粘りを薄めて出しやすくする（去痰薬）。風邪、気管支炎、副鼻腔炎など |
| 主なジェネリック | カルボシステインDS50%「サワイ」（沢井製薬）、「トーワ」（東和薬品）、「タカタ」（高田製薬）など |
