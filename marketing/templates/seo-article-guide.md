# SEO記事ガイド：おくすり味ナビ

---

## ⚠ 出典ルール（最上位ルール・全記事共通）

医薬品情報の記事は誤りが健康被害に直結する。**出典と紐づかない情報は一切書かない。**

### 書いてよい情報（出典が明確なもののみ）

| 情報の種類 | 許可される出典 | 記事内での出典表記 |
|-----------|--------------|------------------|
| 食品との飲み合わせ相性（◎/△/✕） | NCCHD公開PDF | 「国立成育医療研究センター薬剤部の公開資料に基づく」 |
| 薬の基本情報（商品名、一般名、製造元、用途） | 添付文書・インタビューフォーム | 出典名を記事末尾に併記 |
| 味の表記 | NCCHD公開PDF上の表記のみ | 「（出典PDFの表記による）」 |
| その他の情報 | 出典URLまたは文献名を明示できるもの | 記事内に出典を併記 |

### 書いてはならない情報

- [ ] 出典なしの「飲ませ方のコツ」「鉄則」（もっともらしくても根拠不明なら書かない）
- [ ] 出典なしの薬理学的メカニズムの説明（「コーティングが酸で溶ける」等）
- [ ] 出典なしの薬同士の相互作用（「○○は酸性なので△△と混ぜるな」等）
- [ ] NCCHD相性データに対する独自の理由づけ（「酸味同士で自然になじむ」等）
- [ ] 食品名のアレンジ（PDF上「アイス」を「チョコアイス」にする等）
- [ ] 相対評価・順位づけ（「一番のおすすめ」「トップクラスに苦い」「比較的飲みやすい」等）
- [ ] ジェネリック医薬品の味・相性が先発品と同じという断定（PDFがジェネリック別に検証していない限り）
- [ ] アプリ独自データ（mixGood/mixOk/mixBad）の記事への混入

### 相性コードの読み方（厳守）

アプリの `index.html` 内 `officialCompat` の compat 配列：
```
G = 飲みやすい（Good）  → 記事では ◎
O = 変わらない（OK）    → 記事では △
B = 飲みにくい（Bad）   → 記事では ✕
```

食品の順番（`officialFoodCols`）：
```
ココア, プリン, 牛乳, アイス, お茶, ヨーグルト, りんごジュース, オレンジ飲料, 乳酸菌飲料, スポーツ飲料
```

**コードの意味は推測せず、必ず `index.html` 内のレンダリング処理で確認すること。**

## 1. 戦略

### 狙うキーワード

「薬の商品名 + 子供 + 飲ませ方」がメインキーワード。
親が検索するのは「今まさに子どもが薬を飲んでくれない」瞬間。即答性が命。

### 記事の優先順位（検索ニーズが高い順）

| # | キーワード | 現在の1位 | 狙う理由 |
|---|-----------|----------|---------|
| 1 | クラリスドライシロップ 飲ませ方 | ミナカラ | 1位は一覧表なし。勝てる |
| 2 | ムコダイン 粉薬 飲ませ方 | QLife | 薬DBサイト。食品相性の情報なし。勝てる |
| 3 | カルボシステイン 子供 飲み方 | EPARKくすりの窓口 | ムコダインの一般名。両方で検索される |
| 4 | アジスロマイシン 子供 飲ませ方 | ミナカラ | ジスロマックの一般名。苦味が強い |
| 5 | タミフル 粉薬 飲ませ方 | 育児ブログ | インフルシーズンに急増。1位は根拠薄い。勝てる |
| 6 | ワイドシリン 飲ませ方 | クリニックブログ | よく処方される抗生剤 |
| 7 | 粉薬 子供 飲ませ方 まとめ | PMDA | 政府サイト。薬別相性なし。一覧表で差別化可能 |

### 競合との差別化

市場分析（2026-03-18実施）の結果、**粉薬×食品の味の相性を検索できるアプリは日本にも世界にも存在しない**ことが確認された。

| 競合（具体名） | 検索順位の実績 | 弱点 |
|---------------|-------------|------|
| **ミナカラ**（minacolor.com） | 「クラリス 飲ませ方」で1-2位独占 | 飲み合わせ一覧表がない。記事は正確だがスキャンしにくい |
| **PMDA**（pmda.go.jp） | 「粉薬 子供 飲ませ方」で1位 | 政府サイト。薬別の具体的な食品相性がない |
| **キャップスクリニック** | 複数キーワードで上位 | 薬別の相性表あり（最大の脅威）。ただし静的記事で検索・比較不可 |
| **QLife** | 「ムコダイン 飲み合わせ」で1位 | 薬データベースだが味×食品の相性は対象外 |
| **育児ブログ各種** | 「タミフル 飲ませ方」で1位 | 体験談ベース。根拠が薄い。情報が古い |
| **NCCHD PDF** | 各キーワードで10位前後 | 事実上の業界標準データだが、PDFで検索不可・スマホで読めない |

**おくすり味ナビ記事の強み（= 上記すべてに対する差別化）:**
- **唯一のアプリ**: 薬名で検索 → おすすめ/NGが即座にわかるサービスは他に存在しない
- **一覧表の即答性**: 全記事に飲み合わせ一覧表を掲載。ミナカラにもキャップスにもない形式
- **複数薬まとめ機能**: 処方箋に複数の薬がある場合、共通して使える食品を提示。競合には不可能
- **公的資料ベースの信頼性**: NCCHDのデータを正確に構造化。育児ブログの体験談とは次元が違う

## 2. 記事の公開場所

noteで公開する。

- 無料で始められる
- noteドメインは検索エンジンからの評価が比較的高い
- アプリへのリンクを自然に貼れる
- 開発秘話やアプリ紹介の記事も同じアカウントで書ける

記事数が増え、検索流入が安定してきた段階で独自ドメイン移行を検討する。

## 3. 記事テンプレート

### タイトルの付け方

```
【公的資料ベース】〇〇（薬名）の飲ませ方｜おすすめ食品とNG食品まとめ
```

ポイント:
- 薬名を先頭に（検索ヒットのため）
- 「おすすめ」「NG」で即答感を出す
- 「公的資料ベース」で信頼性を示す

---

### 本文の構成

#### 1. 冒頭（悩みに共感 → 即答）

```
子どもに〇〇（薬名）を処方されたけど、飲んでくれない…。

この記事では、国立成育医療研究センターの公開資料をもとに、
相性の良い食品・避けた方がいい食品をまとめました。

✅ おすすめ: △△、□□、▲▲
⚠ 避けた方がいい: ××、◇◇

（※ ◎/△/✕ はNCCHD公開PDFのcompat配列から転記すること）
（※ 食品名はPDF上の表記をそのまま使うこと）
```

冒頭3行で答えを出す。「詳しくは下へ」は離脱の原因。

---

#### 2. 飲み合わせ一覧表

**全記事に必ず入れる。これが最大の差別化要素。**

```
**◎ おすすめ（飲みやすい）**
・（G の食品を列挙）

**△ 変わらない**
・（O の食品を列挙）

**✕ 避けた方がいい（飲みにくい）**
・（B の食品を列挙）
```

NCCHD公式10食品（ココア、プリン、牛乳、アイス、お茶、ヨーグルト、りんごジュース、オレンジ飲料、乳酸菌飲料、スポーツ飲料）を必ず網羅する。**これ以外の食品は追加しない。**

各食品に「ひとこと」説明をつけない（出典にない理由づけの混入を防ぐ）。

---

#### 3. 複数の薬を処方された場合

```
複数の薬を処方されたとき、全部に共通して使える食品を確認したい場合は
「おくすり味ナビ」の複数薬まとめ機能が便利です。
薬を選ぶだけで、共通のおすすめとNGが一目でわかります。

📱 おくすり味ナビ:https://okusuri-navi.app/
```

**このセクションにはアプリのスクショを必ず1枚入れる。** CTA直前にスクショを入れることで「こういう画面で確認できる」と伝わり、タップ率が上がる。

---

#### 4. この薬について（表形式）

```
| 項目 | 内容 |
|------|------|
| 商品名 | 〇〇 |
| 一般名 | △△ |
| 製造元 | □□ |
| 味 | ××（出典PDFの表記による） |
| 主な用途 | ... |
| 主なジェネリック | ... |
```

**注意:** 味の表記はNCCHD PDF上の表記のみ。アプリ独自の味データ（tasteDetail, flavorLabel等）を記事に使わない。

---

#### 5. 末尾: 出典＋アプリ紹介

アプリへのリンク（CTA）は記事中盤の「複数薬まとめ機能」紹介箇所に1箇所だけ配置する。
末尾にもURLを入れると宣伝感が出るため、アプリ名の言及のみにとどめる。

```
---
出典: 国立成育医療研究センター薬剤部
「粉薬と服薬補助食品の飲み合わせ」（2018年）
https://www.ncchd.go.jp/hospital/about/section/medicine/nomiawase.pdf

本記事は医療行為の代替ではありません。
服薬に関する最終判断は医師・薬剤師にご確認ください。
味の感じ方には個人差があります。お子さんの様子を見ながらお試しください。
---

📱 おくすり味ナビ — 公的資料ベースで粉薬の味・飲み合わせを確認できるアプリです。
スマホのホーム画面に追加するとアプリとして使えます。
```

## 4. 総合記事テンプレート（薬名を特定しない検索向け）

### タイトル例

```
【保存版】子どもの粉薬の飲み合わせガイド｜薬別おすすめ＆NG食品一覧
```

### 構成

1. 冒頭: 「粉薬が飲めない」は多くの親の悩み → この記事で一覧にまとめた
2. **薬ごとのおすすめ＆NG一覧表**（主要5〜8薬をまとめた横断表。これが記事の核）
3. 複数薬が処方された時 → アプリの「まとめ機能」へ誘導
4. 出典＋アプリ紹介

### 横断表の例

```
| 薬名 | アイス | ヨーグルト | スポーツ飲料 | ... |
|------|:-----:|:---------:|:----------:|-----|
| クラリス | ◎ | ✕ | ✕ | ... |
| ムコダイン | ◎ | ◎ | ◎ | ... |
| ... | ... | ... | ... | ... |
```

※この表はNCCHD公開PDFのデータ（アプリのcompat配列）から生成すること。絶対に推測で埋めない。
※食品名はPDF上の表記（「アイス」等）をそのまま使う。

## 5. 記事作成チェックリスト

記事を書くたびにこのチェックリストを使う。

### 執筆前
- [ ] `index.html` の `officialCompat` から対象薬のcompat配列を取得した
- [ ] compat配列の G/O/B を正しく解釈した（G=飲みやすい, O=変わらない, B=飲みにくい）
- [ ] `officialFoodCols` の食品順と照合した

### 執筆中
- [ ] タイトルに薬名が入っている
- [ ] 冒頭で結論（おすすめ/NG）を出している
- [ ] NCCHD公式10食品の一覧表を入れた
- [ ] 食品名はPDF上の表記をそのまま使っている（アレンジしていない）
- [ ] 各食品に「ひとこと」説明をつけていない
- [ ] アプリへの導線を自然に入れた（複数薬まとめ機能の箇所に1箇所のみ）
- [ ] 出典を明記した
- [ ] 「個人差があります」等の注意書きが入っている

### 公開前（出典チェック）
- [ ] 記事内の全情報について「この情報の出典は何か？」を1行ずつ自問した
- [ ] 出典を示せない情報が1つも残っていない
- [ ] ◎/△/✕ の全ペアがcompat配列と一致することを最終確認した
- [ ] 断定表現・相対評価・順位づけがないか読み返した

### 公開後
- [ ] noteの記事URLをXで投稿した
- [ ] Google Search Console でインデックス登録をリクエストした
