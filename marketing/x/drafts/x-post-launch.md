# おくすり味ナビ リリース告知 X投稿案

## 投稿案1: 親向け（メイン）

```
子どもの粉薬、何に混ぜたら飲めるか毎回ググってた。

ヨーグルトに混ぜて余計まずくなったこともある。

調べたら国の研究機関が飲み合わせデータを公開してた。でもPDFで見づらい。

だから薬名を入れるだけで「おすすめ食品」と「NG食品」がすぐわかるアプリにした。

📱 おくすり味ナビ
https://okusuri-navi.app/
```

## 投稿案2: 薬剤師向け

```
服薬指導で「何に混ぜたらいいですか？」と聞かれたとき用のアプリを作りました。

国立成育医療研究センターの公開資料ベースで、粉薬18種×食品約30種の相性を検索できます。

複数薬の処方時も、全部に共通して使える食品が一覧で出ます。

📱 おくすり味ナビ
https://okusuri-navi.app/

#薬剤師 #服薬指導
```
